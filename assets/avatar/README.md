# Слои Симплика

## Текущий локальный набор, 26 октября 2026

Худи v2 утверждено пользователем 24 октября. На его основе перерисованы
халат, шапочка, скафандр, обычные/защитные очки и наушники встроенным image_gen.
Все семь новых PNG — 1000×1000 RGBA, с прозрачными отверстиями и фоном,
посадка заложена при экспорте. Масштабирующих трансформаций в renderer нет.
Эмоции happy/wink/wow остались исходными PNG 1080×1080; улыбка, тело,
пять цветов и механизм hue-rotate не менялись.

Координаты, исходники генерации, промпты, экспорт и результаты проверок:
[дизайн набора](../../docs/design/simplik-set-2026-10-24/README.md).
26 октября набор опубликован на сайте: код `35830d1`, образ
`mosphysics:avatar-set-35830d1`. Отчёт: [выпуск](../../docs/DEPLOY_2026-10-26.md).

Скафандр временно скрывает одежду и наушники только при отрисовке.
AvatarConfig и сохранённые значения не меняются; после снятия шлема вещи
возвращаются. Очки совместимы со скафандром, шапочка — с наушниками.
Орбиты по-прежнему только в большом редакторе, миниатюра без орбит.

Исходный набор перед заменой сохранён в отдельных игнорируемых папках:
- `artifacts/avatar-backups/before-redraw-2026-10-23-m220XC/`
