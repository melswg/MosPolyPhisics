# Значки соцсетей

SVG имеют общий холст 24×24 и скругление 6, одинаковый размер задаёт CSS.
Прежние PNG сохранены. Telegram, VK и Pinterest адаптированы из векторных
знаков [Simple Icons](https://github.com/simple-icons/simple-icons), CC0.
YouTube, Rutube и Дзен построены геометрически по прежним значкам проекта.

26.10.2026: в Chrome пользователя ссылка Дзена присутствует в DOM, но её
computed display — none, при этом авторские стили задают flex, атрибуты
hidden и style отсутствуют. Предполагается косметический фильтр расширения;
конкретное расширение не установлено. Изменение картинки не устраняет фильтр.
