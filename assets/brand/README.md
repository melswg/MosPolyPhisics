# Брендовые assets

Файлы перенесены из текущего репозитория «МосПолиФизикс» 18 сентября 2026 года
как визуальная основа экспериментальной версии:

- `logo.svg` — основной логотип;
- `mas.svg` — маскот;
- `icon-*.svg` — иконки основных разделов;
- `icons/user-circle.svg` — аккаунт;
- `backgrounds/pattern-physics.svg` — фоновый физический паттерн.

Hermes может менять размещение и оформление, но не должен подменять эти файлы
сгенерированным брендом без просьбы пользователя. Не считать наличие иконки
подтверждением готовности соответствующего раздела.
