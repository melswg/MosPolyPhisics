# Цитаты из таблицы

Лист «Цитаты» использует колонки `quote`, `author`, `source`, `status`.
Синхронизация раз в час публикует только `готово`; ошибка сохраняет прежний
снимок. Источник — полный HTTPS-адрес, текст и автор обязательны.
Удаление строки или смена статуса убирает только соответствующие цитаты таблицы.
Существующие локальные цитаты и другие данные не изменяются.

Для таблицы проекта задайте `MOSPHYSICS_QUOTES_SHEET_GID=2008468931`.
ID берётся из `MOSPHYSICS_NEWS_SHEET_ID`; отдельную таблицу можно указать через
`MOSPHYSICS_QUOTES_SHEET_ID`. Пустой GID отключает синхронизацию.
Ручной запуск: `python -m backend.quote_sync`.
Миграция 5 добавляет отдельную таблицу с источниками.

`GET /api/quote` сохраняет поле `quote` прежнего контракта и добавляет
`text`, `author`, `source`. Главная показывает случайную проверенную цитату
при каждом открытии, с автором и источником; повтор случайного выбора допустим.
Ответ не кешируется. Цитаты без источников из прежнего seed на главной не показываются.
