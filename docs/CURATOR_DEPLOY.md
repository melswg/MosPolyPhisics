## Откат приложения

Прежний контейнер сохранён как `mosphysics-before-curator-8e6d730`.
После явного разрешения на откат:

```sh
docker stop mosphysics-hermes-rebuild-prod
docker rename mosphysics-hermes-rebuild-prod mosphysics-curator-rolled-back-8e6d730
docker rename mosphysics-before-curator-8e6d730 mosphysics-hermes-rebuild-prod
docker start mosphysics-hermes-rebuild-prod
```

БД не заменять резервной копией при обычном откате приложения: это потеряет
новые пользовательские изменения. Совместимость старого образа со схемой 6
проверена на копии.

GitHub Actions выполняет тесты, автодеплой пропускается. Скрипт
`deploy/deploy-vps.sh` рассчитан на systemd/venv, а рабочая версия запущена
в Docker. Настройка автодеплоя требует отдельной задачи; в этом обновлении
workflow и другие приложения VPS не изменялись.
