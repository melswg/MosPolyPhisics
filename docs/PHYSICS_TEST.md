# Первый законченный тест

Источник формулировок: лист «Вопросы тестов» таблицы проекта, строки с номерами
2, 12, 13, 14, 15, проверенные 11.10.2026. Формулировки и объяснения уточнены
по OpenStax College Physics 2e; источник доступен в разборе каждого вопроса.
Остальные строки не импортированы: среди них есть пропуски вариантов,
несовпадения правильного ответа и физические неточности. Статус «готово»
в таблице сам по себе не заменяет содержательную проверку.

Явный импорт в выбранную БД (не выполняется при обычном запуске):

```bash
python -m backend.import_physics_test /tmp/mospolyphysics-showcase.sqlite
MOSPHYSICS_DATABASE=/tmp/mospolyphysics-showcase.sqlite uvicorn backend.main:app
```

Повторный импорт сохраняет ID и не создаёт дубли. При чужой правке существующего
теста команда отказывается его перезаписывать. Прочие тесты и пользователи
сохраняются. Production-импорт требует разрешения, резервной копии и проверки
миграции 7 на восстановленной копии; локальная команда не означает деплой.

Каталог получает `/api/tests`, карточки ведут на `/test?id=...`.
GET вопросов не содержит правильных ответов, объяснений или источников.
POST `/api/test/submit` требует ровно один индекс 0–3 для каждого вопроса;
пропуски, чужие ID и неверные типы возвращают 422, неизвестный тест — 404.
Ответ сохраняет `correct`, `total`, `percent` и добавляет `review` с выбранным
и правильным вариантом, объяснением и источником. История попыток не сохраняется.
