# Объёмные орбиты Симплика

26 октября пользователь попросил вернуть орбитам большого предпросмотра вид
маскота главной, вместо одинаковых однотонных эллипсов за персонажем.
Главная использует assets/brand/mas.svg со встроенным PNG 1080×1080;
сам исходник, тело, эмоции, новая одежда и сохранённые настройки не менялись.

Геометрия измерена по исходному рендеру: пиксели сферы и шариков исключены,
к трём проекциям окружностей подобраны эллипсы. Измерения исходного PNG:

| Орбита | Центр | Радиусы | Наклон |
|---|---|---|---|
| Почти горизонтальная | (526.59,546.31) | (379.27,132.03) | −7.87° |
| Наклон вправо вниз | (506.36,541.58) | (413.52,119.64) | 30.117° |
| Наклон вправо вверх | (554.61,548.81) | (461.19,164.09) | −43.189° |

Регистрация в renderer: исходный центр сферы около (543,538) переходит
в неизменный (500,490), линейный коэффициент 1.07 приводит радиус исходной
сферы к текущим 180 единицам. Это фиксированные SVG-координаты, без изменения
body/color и CSS-масштабов. Шарики привязаны к исходным точкам орбит.

Задние полудуги рисуются до сферы, передние — после одежды и аксессуаров.
У трубок есть затенённый край, градиентная середина и узкий блик; шарики
используют сферический radialGradient. Передние дуги отбрасывают мягкую тень,
ограниченную кругом тела, чтобы не затемнять фон страницы.
Фильтр hue-rotate использует прежние пять значений. В миниатюре орбит и их
декоративных defs нет. ID градиентов/clip/filter уникальны у каждого рендера.

## Проверки

- Регрессионная Node-проверка сначала падала на отсутствии передних дуг,
  после исправления проходит. Проверяются план поверх одежды, три шарика,
  отсутствие орбит в миниатюре и после переключения режима, уникальность ID
  двух больших предпросмотров на одной странице.
- 90 pytest, Node avatar_renderer/account_navigation/password_reset/typography
  и git diff --check — успешно.
- Во встроенном браузере просмотрено сравнение «главная / было / стало»
  в светлой и тёмной темах, без одежды и с худи; переключены все пять цветов.
  Снимки comparison-light.png и comparison-hoodie-dark.png сохранены рядом.
- Маскот главной остаётся исходным; миниатюра 40/64 px по-прежнему без орбит.

страница находятся в игнорируемом artifacts/orbits-2026-10-26/.
