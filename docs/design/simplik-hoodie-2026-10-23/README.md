## Единая система координат

Все координаты ниже — SVG viewBox 1000×1000, начало сверху слева.
Исходные PNG 1080×1080 отображаются в этом viewBox с коэффициентом 1000/1080.
Новый слой нормализуется в 1000×1000, без CSS-масштабирования.

| Опора | Координаты |
|---|---|
| Тело | центр (500,490), радиус 180; x=320…680, y=310…670 |
| Улыбка: глаза | (444,491), (556,491); rx=25, ry=35 |
| Улыбка: рот | x=480…520, y≈545…561 с учётом обводки |
| Радость, bbox PNG / 1.08 | x≈426…581, y≈476…576 |
| Подмигивание, bbox PNG / 1.08 | x≈422…581, y≈461…555 |
| Удивление, bbox PNG / 1.08 | x≈422…580, y≈459…582 |
| Очки | линзы x=404…484 и 516…596; y=455…530 |
| Наушники | дуга вокруг верхней сферы; чашки y=451…544 |
| Шапка | верх головы y=310, боковые точки около x=390/610 |
| Худи: планируемый вырез | края (335,545)/(665,545), середина около (500,582) |
| Худи: планируемый низ | (500,678), ткань немного выступает за сферу |

Порядок renderer: орбиты → сфера → одежда → лицо → аксессуар → головной убор.
Большой предпросмотр: viewBox 0 0 1000 1000, орбиты включены явно.
Миниатюра: viewBox 240 220 520 520, орбит нет. Сохраняем оба режима.
Контроль одежды: не заходить в область рта удивления до y≈582 по центру.

Фактический экспорт v1: 1000×1000 RGBA, непустые пиксели
x=322…677, y=538…682; 96,56% холста полностью прозрачны.
Генератор выдал 1254×1254, поэтому слой при экспорте подогнан по двум осям
к измеренной нижней части сферы: trim → 356×145 → (322,538).
Это явная геометрия PNG, без трансформаций в renderer или CSS.
Исходная генерация сохранена в hoodie-source.png, воспроизводимый экспорт —
normalize-layer.cjs (Node + sharp), затем render-review.cjs.

## Известные сочетания

- Очки и защитные очки занимают один слот, одновременно не выбираются.
- Худи и халат занимают один слот, одновременно не выбираются.
- Шапочка и шлем занимают один слот, одновременно не выбираются.
- Шлем поверх наушников перекрывает их; низ шлема перекрывает одежду.
  Предложение для согласования: цельный космический образ; хранить прежние
  значения одежды и аксессуара для возврата. До согласования контракт не менять.
- Шапочка и наушники требуют согласования дуги при перерисовке обеих вещей.
