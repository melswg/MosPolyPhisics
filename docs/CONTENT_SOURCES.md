Чтение после записи подтвердило A2:F3. Прочие ячейки, оформление и права
не менялись. События и новелла не заполнены выдуманными сведениями.

Пока `/api/videos` объединяет прежний локальный каталог с опубликованными
новостями рубрики «Видео» (без копирования в отдельную БД и без дублей URL).
Удаление/смена статуса такой новости при успешной синхронизации убирает её
из видеокаталога. Сам лист «Видео» автоматически не импортируется:
новые видео для текущей версии публикуются также через «Новости» с category=Видео.
Сайт открывает исходный пост Telegram, оригинал видео не скачивает.

Страницы видео, календаря и дневника теперь читают существующие API.
События фильтруются по месяцу/выбранному дню; пустой список и сбой различаются.
