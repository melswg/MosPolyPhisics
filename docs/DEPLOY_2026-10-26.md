## Откат

Прежний образ: `mosphysics:preview-orbits-c964d7f`, контейнер
`mosphysics-before-avatar-set-35830d1`, сохранён остановленным.
Новый сценарий выпуска автоматически возвращает прежний контейнер при ошибке
переключения; это не потребовалось. После свежей копии данных и проверки имён
ручной откат приложения без замены рабочей БД:

```sh
docker stop mosphysics-hermes-rebuild-prod
docker rename mosphysics-hermes-rebuild-prod mosphysics-avatar-set-35830d1-held
docker rename mosphysics-before-avatar-set-35830d1 mosphysics-hermes-rebuild-prod
docker start mosphysics-hermes-rebuild-prod
curl --fail https://mospolyphysics.ru/api/health
```

Не восстанавливать switch.sqlite при обычном откате образа: это может потерять
более поздние пользовательские изменения. Старые образы и копии не удалялись.
