## Структура и запуск по исходному коду

- backend/main.py: FastAPI, публичные API, регистрация, JWT и выдача frontend.
- backend/models.py: SQLite, автоматическое создание таблиц и демоданных, проверка тестов.
- frontend/: 13 HTML-страниц, 13 JavaScript-файлов, CSS и графика.
- Dockerfile и docker-compose.yml: приложение на порту 8000, том для SQLite.
- README.md, PROJECT_CONTEXT.md, PAGES_STRUCTURE.md, OPENAPI.md: документация прежнего MVP.

Заявленный локальный запуск из корня: `uvicorn backend.main:app --reload`.
Docker запускает тот же модуль через uvicorn; сборка использует backend/requirements.txt.
Это описание конфигурации, а не подтверждение успешного полного запуска.

Корневой requirements.txt содержит fastapi, uvicorn и pydantic, но не PyJWT/passlib.
Backend-список содержит fastapi, uvicorn, passlib[bcrypt], PyJWT без закреплённых версий.
Эти способы установки не согласованы. В зависимости для хеширования не включён
Argon2-backend, хотя create_user выбирает argon2; fallback ловит ошибку импорта,
а не отсутствие backend при hash(). Исправление относится к задаче 2.

## Наличие функций

| Раздел | Что есть | Что остаётся |
|---|---|---|
| Главная | Навигация, маскот, темы, случайная цитата через API | Единая цитата дня, завершённый подвал |
| О нас | Описание и карточки | Команда и сотрудничество; часть карточек ведёт на maintenance |
| Новости | Список и API, две демозаписи | Реальные материалы, публикация, обложки и отдельная страница |
| Видео | API и iframe | Реальный каталог; один демонстрационный ролик в seed |
| Календарь | Список двух демособытий | Сетка месяца, переключение и выбор дня |
| Новелла | Страница и API дневника | Настоящие скриншоты, лор и сборка; скачивание ведёт на maintenance |
| Тесты | Два теста, пять вопросов, серверный подсчёт | Контент, категории и объяснения; стрелки не переключают вопросы |
| Цитаты/ЕГЭ | Карточки-переходы | Отдельные сценарии пока заглушки |
| Пользователи | Формы, API, JWT в localStorage | Исправление установки, роли, сессии, восстановление |
| Администрирование | Нет реализованного редакторского процесса | Черновики, проверка, публикация и права |
| Эксплуатация | Docker и том БД | CI, миграции, HTTPS, копии, мониторинг |

Дополнительные ограничения исходного кода:
- Известный запасной JWT-секрет в конфигурации; небезопасно публиковать с ним.
- В кабинете пользовательские строки вставляются в innerHTML; требуется безопасное отображение.
- Демоматериалы автоматически появляются в пустых таблицах.
- После успешной загрузки видео/дневника может оставаться «Загрузка…».
- В главной указан отсутствующий fonts/FT40Roman.woff2; проверка href/src это не выявляет.
- Истории попыток и административного API нет; они не должны предполагаться существующими.

Это статические наблюдения; наличие проблемы в конкретном публичном развёртывании
не проверялось. Полный security-аудит не проводился.
