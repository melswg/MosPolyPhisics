# Как заполнять таблицу материалов МосПолиФизикс

Инструкция по структуре таблицы, проверенной 6 октября 2026 года:
[Новости МосПолиФизикс](https://docs.google.com/spreadsheets/d/1Mr5aAkXqf3oxg-hXaZcZk2AKy15kQF_rkkZrFb6rdz4/edit?usp=sharing).

## Общие правила

- Одна строка — одна новость, один участник, одно видео, один проект, одно событие, одна цитата или один вопрос.
- Заполняйте данные со второй строки. Первую строку с названиями колонок не меняйте.
- Даты записывайте в формате `06.10.2026`. Укажите полную дату с годом.
- В колонках со ссылками вставляйте полный адрес, начинающийся с `https://`, а не слово «ссылка» или название файла.
- Файлы на Google Диске должны открываться по ссылке без запроса доступа. Для фотографий и превью используйте ссылки на отдельные файлы.
- Статус `собрано` означает, что материал внесён и ожидает проверки. `уточнить` — не хватает данных или есть вопрос. `готово` — всё заполнено и проверено.
- Статус `готово` ставьте последним. Факты, ссылки, авторство и правильные ответы должны быть проверены человеком.

**Сейчас автоматически публикуется только лист «Новости».** Сайт проверяет его раз в час и забирает строки со статусом `готово`. Остальные листы используются для подготовки материалов; их автоматическая публикация пока не подключена.

## Лист «Новости»

Одна строка — одна публикация в ленте.

| Колонка | Что вписывать |
|---|---|
| `title` | Короткий понятный заголовок, например «Комикс об отражении света». Без длинного вступления; до 200 символов. |
| `date` | Дата публикации исходного поста, например `06.10.2026`. |
| `category` | Рубрика материала, например «Видео», «Физика в буквах», «Физики говорят». Для одинаковых рубрик используйте одинаковое название. |
| `text` | Текст новости для сайта. Для ленты достаточно короткого описания; подробный разбор добавлять необязательно. Не оставляйте пустым. |
| `source` | Ссылка на конкретный публичный пост Telegram: `https://t.me/имя_канала/номер_поста`. Ссылка на канал целиком или приглашение в закрытый канал не подходит. |
| `images` | Ссылки на фото или видеофайлы на Google Диске. Для видео сайт использует только превью. Несколько ссылок вставляйте в одну ячейку, каждую с новой строки. Первая картинка будет обложкой карточки. Если картинок нет, оставьте пустым или поставьте `-`. |
| `status` | `собрано`, `уточнить` или `готово`. На сайт попадает только `готово`; написание «Готово» тоже поддерживается. |
| `comments` | Внутренние замечания для коллег: что проверить, чего не хватает, куда материал ещё можно использовать. На сайте не показываются. |

### Как опубликовать или убрать новость

1. Добавьте строку, заполните данные и поставьте `собрано`.
2. Проверьте заголовок, текст, дату, источник и доступ к изображениям.
3. Поставьте `готово`. При следующей успешной проверке таблицы новость появится на сайте.
4. Чтобы исправить новость, отредактируйте её строку. Обновление тоже произойдёт при следующей успешной проверке.
5. Чтобы снять новость с публикации, смените статус на `уточнить` или удалите строку. Она исчезнет при следующей успешной проверке.

Не дублируйте один и тот же `source` в нескольких готовых строках. Не вставляйте ссылки на папки вместо файлов: папки требуют отдельной настройки.

Если в готовой строке неверная дата, неподходящий источник или недоступный файл, обновление всей ленты может не пройти. До исправления сайт сохранит предыдущую успешную версию. На время уточнения снимайте с такой строки статус `готово`.

Комментарий «Страница видео» или «Страница комиксов» сам по себе не размещает материал в этом разделе: `comments` служит только для общения внутри команды.

## Лист «Команда»

Одна строка — один участник проекта.

| Колонка | Что вписывать |
|---|---|
| `name` | Имя и фамилия участника в том виде, в котором их можно разместить на сайте. |
| `command` | Направление или группа участника: «Разработка», «Дизайн», «Ресерч». Если направлений несколько, перечислите их через запятую. |
| `role` | Конкретная работа в проекте: «Фуллстек разработка», «Подготовка вопросов для тестов», «Дизайн интерфейса». |
| `status` | `готово`, если имя, направление и роль подтверждены участником; иначе `собрано` или `уточнить`. |

`command` здесь означает направление работы, а не команду для программы. Фотографии участников в текущей структуре листа не предусмотрены.

## Лист «Видео»

Одна строка — одно видео.

| Колонка | Что вписывать |
|---|---|
| `title` | Название видео, понятное без просмотра. |
| `date` | Дата публикации видео. |
| `description` | Короткое описание: о чём видео и что зритель узнает. Обычно достаточно 1–3 предложений. |
| `video source` | Ссылка на само видео или страницу, где оно воспроизводится. Указывайте конкретный ролик, а не главную страницу канала. |
| `preview source` | Ссылка на отдельную картинку-обложку. Для Google Диска — ссылка на доступный файл изображения. |
| `status` | `готово`, когда описание проверено, видео открывается и превью доступно; иначе `собрано` или `уточнить`. |

Если ролик есть только в Telegram, можно указать ссылку на конкретный пост. Подходящий способ показа на сайте выбирается при подключении раздела. Одна запись на этом листе пока не создаёт автоматически новость в ленте.

## Лист «Проекты»

Одна строка — один самостоятельный проект или материал, например визуальная новелла.

| Колонка | Что вписывать |
|---|---|
| `title` | Название проекта. |
| `description` | Короткое описание: что это, для кого и что можно посмотреть или сделать. |
| `image source` | Ссылка на обложку, иллюстрацию или скриншот проекта. |
| `project source` | Ссылка на сам проект: страницу, репозиторий, готовую сборку или файл для скачивания. Выберите адрес, который должен открыть посетитель. |
| `status` | `готово`, если описание проверено и нужные материалы доступны. Если сборки или обложки ещё нет — `уточнить`. |

Не указывайте несуществующую сборку или будущую ссылку как готовую. Если проект ещё разрабатывается, это должно быть понятно из описания.

## Лист «События»

Одна строка — одно событие.

| Колонка | Что вписывать |
|---|---|
| `title` | Название события: защита проекта, день открытых дверей, встреча, лекция. |
| `date` | Дата проведения события. |
| `description` | Что будет происходить, для кого событие и как участвовать. Если известно время начала, укажите его здесь вместе с часовым поясом. |
| `place` | Место: корпус и аудитория, полный адрес или онлайн-площадка. |
| `source` | Ссылка на официальный анонс или страницу события, по которой можно проверить сведения. |
| `status` | `готово`, когда дата, место и описание подтверждены; иначе `собрано` или `уточнить`. |

Если событие проходит онлайн, укажите это в `place`, а ссылку для подключения — в `description`. В текущем листе нет отдельной колонки времени.

## Лист «Цитаты»

Одна строка — одна цитата.

| Колонка | Что вписывать |
|---|---|
| `quote` | Сам текст цитаты. Если это перевод, обозначьте это и приведите сведения о переводе в `source`, когда они известны. |
| `author` | Полное имя автора, которому принадлежит цитата. |
| `source` | Проверяемый источник: ссылка на публикацию, интервью, письмо или книга с названием и страницей. Для перевода желательно указать также оригинальный источник. |
| `status` | `готово` только после проверки текста и авторства. Если цитата известна по картинке или подборке без первоисточника — `уточнить`. |

Пересказ мысли не выдавайте за дословную цитату. Одного изображения с подписью известного учёного недостаточно для подтверждения авторства.

## Лист «Вопросы тестов»

Одна строка — один вопрос с четырьмя вариантами ответа.

| Колонка | Что вписывать |
|---|---|
| `test` | В текущем листе здесь фактически стоит порядковый номер вопроса: `1`, `2`, `3` и далее. Продолжайте эту нумерацию. Распределение вопросов по отдельным тестам пока не задано. |
| `question` | Полная формулировка вопроса. Для задачи укажите все необходимые условия, числа и единицы измерения. |
| `option_a` | Первый вариант ответа. |
| `option_b` | Второй вариант ответа. |
| `option_c` | Третий вариант ответа. |
| `option_d` | Четвёртый вариант ответа. |
| `correct_answer` | Полный текст правильного варианта, точно совпадающий с одним из четырёх ответов. Например, `Ньютон`, если так записано в варианте. Так заполнены существующие вопросы. |
| `explanation` | Объяснение, почему этот ответ правильный. Для вычислительной задачи — формула, подстановка и результат с единицами. По возможности укажите, в чём ошибка остальных вариантов. |
| `status` | `готово`, если формулировка однозначна, все варианты заполнены, правильный ответ и объяснение проверены; иначе `собрано` или `уточнить`. |

В текущем формате предполагается ровно один правильный ответ. Варианты не должны дублироваться. Не выделяйте правильный вариант словами «верно», галочкой или другим намёком внутри `option_a`–`option_d`.

Название `test` сейчас не соответствует содержимому колонки: это номер вопроса. Если позже появятся несколько отдельных тестов, номер вопроса и принадлежность к тесту нужно будет разделить перед подключением автоматического импорта.

## Короткая проверка перед статусом «готово»

1. Заполнены все данные, нужные для материала.
2. Текст прочитан и исправлен; факты и авторство проверены.
3. Все ссылки открываются, файлы доступны без запроса разрешения.
4. Внутренние замечания не попали в текст для посетителя.
5. На листе «Новости» нет дубликата ссылки на исходный пост.

Сохранение в Google Таблицах происходит автоматически. Отдельно отправлять файл разработчику для каждой новой новости не требуется.
