## Установка и данные

```bash
python -m backend.import_learning_tests backend/database.sqlite
```

Команда использует явно переданный путь, не запускается автоматически.
Создаёт четыре набора / 20 вопросов, включая уже существующий первый набор.
Повторный импорт не дублирует записи. До вставки проверяет все существующие
наборы по slug, названию, описанию и вопросам; при конфликте транзакция не
добавляет остальные наборы и не перезаписывает чужие правки.
Категории каталога: `quotes-*`, `fun-*`; прочие наборы — физика.

Локальной `backend/database.sqlite` до работы не было. Она явно создана
импортом; повторная команда вернула те же ID 1–4. БД игнорируется Git.
Браузер проверялся с отдельной `/tmp/mospolyphysics-polish-20261021.sqlite`.
Временные аккаунты регистрации создавались только в этой проверочной БД.

Новой миграции нет; используется существующая схема 7. При обновлении более
старой установки действует обычный механизм миграций проекта. Новые переменные
окружения и Python-зависимости не нужны. ЕГЭ-задачи — версионируемый каталог
в коде; для их работы импорт в БД не нужен.
Для production нужны отдельно разрешённый выпуск и явный импорт в проверенную
копию рабочей БД с резервным копированием по существующему процессу.

пользователем. Для завершения страницы новеллы нужны реальные сюжет,

и отдельно разрешённый выпуск; они автоматически не начинаются.
