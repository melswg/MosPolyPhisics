## Откат приложения

данных. Следующая процедура возвращает проверенный старый образ без замены БД:

```sh
docker stop mosphysics-hermes-rebuild-prod
docker rename mosphysics-hermes-rebuild-prod mosphysics-polish-a229087-held
docker rename mosphysics-before-polish-a229087 mosphysics-hermes-rebuild-prod
docker start mosphysics-hermes-rebuild-prod
curl --fail https://mospolyphysics.ru/api/health
```

Имя `mosphysics-polish-a229087-held` должно быть свободно. Не восстанавливать
`switch.sqlite` при обычном откате образа: это может потерять более поздние
пользовательские изменения. Совместимость прежнего приложения с текущей схемой
и новыми тестами проверена на копии. Старые образы, контейнеры и копии сохранены;
очистка Docker не выполнялась.

SMTP, перезагрузка VPS и перенос копии на отдельный сервер в этом выпуске
не проверялись. Новелла остаётся отложенной по решению пользователя.
