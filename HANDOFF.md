## Грабли этой сессии

- macOS-архив тащит AppleDouble-файлы `._*`, их нужно удалять на сервере.
- В вариантах пути к бренду абсолютные (`/assets/brand/...`), поэтому каталог с
  ассетами обязан лежать в корне отдаваемого сайта.
- Публичный IP сервера нужен только для ссылок коллегам: по tailnet HTTP-порты
  80, 443, 9090 и 9091 недоступны, доступен только SSH.
- Полные снимки страниц снимаются через `Page.captureScreenshot` с
  `captureBeyondViewport`, при этом липкие шапки дублируются, их нужно временно
  переводить в `position: static`.
- Сетки вида `repeat(12, 1fr)` вызывают переполнение: для текстовых ячеек нужен
  `minmax(0, 1fr)`.
- Логотип `logo.svg` использует аддитивное смешивание и читается только на тёмной
  подложке.
