# МосПолиФизикс

Образовательный веб-ресурс для студентов и абитуриентов, посвященный физике. Проект разрабатывается в рамках университетской программы.

## Функционал прототипа
- **ХАБ (главная страница):** навигация, маскот "Симплик", динамический блок «Цитата дня».
- **Информационный блок:** разделы «О нас» и «Новости».
- **Интерактив:** подготовка к ЕГЭ, тесты и цитаты великих физиков.
- **Проектный блок:** видеоматериалы, календарь событий и визуальная новелла.
- **Личный кабинет:** регистрация и вход пользователей.

## Стек технологий
- **Frontend:** HTML5, CSS3 (адаптивный дизайн, темная/светлая темы), JavaScript.
- **Backend:** Python 3, FastAPI.
- **Database:** SQLite.

## Локальный запуск

Единственный список прямых Python-зависимостей проекта — корневой
`requirements.txt`. Создайте окружение и запустите приложение из корня
репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
uvicorn backend.main:app --reload
```

После запуска сайт доступен на <http://localhost:8000>, а проверка состояния —
на <http://localhost:8000/api/health>.

По умолчанию SQLite-файл создаётся как `backend/database.sqlite`. Для отдельной
локальной или тестовой БД задайте `MOSPHYSICS_DATABASE`, например:

```bash
MOSPHYSICS_DATABASE=/tmp/mospolyphysics.sqlite uvicorn backend.main:app
```

Для демонстрации подтверждённой новости этапа 2 используйте отдельную локальную
БД и явный импорт (команда не заменяет существующие записи):

```bash
python -m backend.import_stage2_news /tmp/mospolyphysics-showcase.sqlite
MOSPHYSICS_DATABASE=/tmp/mospolyphysics-showcase.sqlite uvicorn backend.main:app --reload
```

Авторизация использует серверную сессию в `HttpOnly` cookie. Для локального HTTP
оставьте `SESSION_COOKIE_SECURE=false`; после включения HTTPS установите значение
`true`. Настройки SMTP для восстановления пароля перечислены в
`backend/.env.example`.

## Docker

Docker использует тот же корневой `requirements.txt`:

```bash
docker compose up --build
```

Приложение будет доступно на <http://localhost:8000>. SQLite хранится в Docker
volume `mosphysics_data`. Остановить контейнеры можно командой
`docker compose down`; volume с данными при этом не удаляется.
