# Миграции схемы

Правила:

- имя файла строго `NNNN_короткое_имя.sql`, например `0001_users.sql`;
- версии идут по возрастанию и не повторяются;
- каждый файл применяется один раз и фиксируется в таблице `schema_migrations`;
- SQL пишется идемпотентно (`CREATE TABLE IF NOT EXISTS`, `ADD COLUMN` после проверки)
  и не удаляет существующие данные;
- файлы не наполняют базу публичными записями, наполнение идёт только явным импортом
  из `content/verified_content.json`.

Применение: `./.venv/bin/python scripts/migrate.py --database data/mosphysics.sqlite`

На H0 доменных миграций ещё нет: схема пользователей и сессий появляется на H3.
Приложение при обычном старте миграции не применяет и ничего не создаёт, кроме
служебной таблицы `schema_migrations`.
