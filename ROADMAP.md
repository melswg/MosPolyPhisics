# Дорожная карта Hermes-версии

Каждый пункт завершается интерфейсом, API/данными, обработкой ошибок, проверками и
обновлением `STATUS.md`. Не начинать все пункты одновременно.

## H0. Основа

- [ ] структура приложения и конфигурация;
- [ ] зависимости и воспроизводимый локальный запуск на 8011;
- [ ] временная БД для тестов;
- [ ] `/api/health`;
- [ ] Docker Compose;
- [ ] базовый pytest.

## H1. Общая оболочка

- [ ] дизайн-токены и две темы;
- [ ] header/footer/mobile navigation;
- [ ] маскот и брендовые assets;
- [ ] адаптивность 390/1440;
- [ ] клавиатура, focus, reduced motion.

## H2. Главная, «О нас», новости

- [ ] главная с назначением и переходами;
- [ ] «О нас» только с подтверждёнными фактами;
- [ ] news API и одна подтверждённая новость;
- [ ] loading/empty/error;
- [ ] браузерная проверка обеих тем и размеров.

## H3. Авторизация

- [ ] пользователи и миграции;
- [ ] Argon2;
- [ ] register/login/me/logout;
- [ ] HttpOnly sessions и CSRF;

- [ ] восстановление пароля с тестовым email transport;
- [ ] тесты валидации, сессий и отзывов.

## H4. Простая админка новостей

- [ ] роли user/admin;
- [ ] локальное назначение admin владельцем;
- [ ] защищённые create/edit API;
- [ ] форма и список;
