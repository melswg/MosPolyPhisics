# Дорожная карта Hermes-версии

Каждый пункт завершается интерфейсом, API/данными, обработкой ошибок, проверками и
обновлением `STATUS.md`. Не начинать все пункты одновременно.

## H0. Основа

- [x] структура приложения и конфигурация;
- [x] зависимости и воспроизводимый локальный запуск на 8011;
- [x] временная БД для тестов;
- [x] `/api/health`;
- [x] Docker Compose;
- [x] базовый pytest.
- [x] зафиксирован контракт совместимости из `API_COMPATIBILITY.md`;
- [x] обычный запуск не создаёт публичные демозаписи.

## H1. Общая оболочка

- [ ] дизайн-токены и две темы;
- [ ] header/footer/mobile navigation;
- [ ] маскот и брендовые assets;
- [ ] адаптивность 390/1440;
- [ ] клавиатура, focus, reduced motion.

## H2. Главная, «О нас», новости

- [ ] главная с назначением и переходами;
- [ ] «О нас» только с подтверждёнными фактами;
- [ ] news API и одна подтверждённая новость;
- [ ] loading/empty/error;
- [ ] браузерная проверка обеих тем и размеров.
- [ ] контент импортируется явно из `content/verified_content.json`;
- [ ] старые непроверенные VPS-новости не переносятся автоматически.

## H3. Авторизация

- [ ] пользователи и миграции;
- [ ] Argon2;
- [ ] register/login/me/logout;
- [ ] HttpOnly sessions и CSRF;
- [ ] состояния аккаунта гостя и пользователя;
- [ ] восстановление пароля с тестовым email transport;
- [ ] тесты валидации, сессий и отзывов.
- [ ] сохранено понятное поведение аккаунта: гость выбирает вход/регистрацию,
  вошедший пользователь видит профиль и выход, техническая ошибка не считается 401.

## H4. Простая админка новостей

- [ ] роли user/admin;
- [ ] локальное назначение admin владельцем;
- [ ] защищённые create/edit API;
- [ ] форма и список;
- [ ] проверка 401/403 и публикации.

## H5. Законченный тест

- [ ] минимум пять проверенных вопросов;
- [ ] серверная проверка;
- [ ] прогресс, результат, объяснения;
- [ ] пустые/неполные ответы и сетевые ошибки;
- [ ] mobile/keyboard.

## H6. Остальные разделы

- [ ] проекты и видео;
- [ ] календарь;
- [ ] визуальная новелла;
- [ ] дополнительные тесты и цитаты;
- [ ] ЕГЭ.

Брать по одному разделу только при наличии реального материала.

Для каждого раздела сначала сверяться с матрицей паритета в
`CURRENT_PRODUCT_INVENTORY.md`. Старое наличие страницы подтверждает требование,
но не подтверждает достоверность её содержимого.

## H7. Надёжность и preview

- [ ] browser tests;
- [ ] backup/restore rehearsal;
- [ ] отдельный preview service/DB/port 9091 после разрешения;
- [ ] HTTPS/SMTP только с предоставленной инфраструктурой;
- [ ] итоговый аудит безопасности и доступности.

## Условие полноценного релиза

H0–H7 — не набор необязательных идей. Полноценный сайт достигнут, когда закрыты
все разделы из `PAGES.md`, фактический функциональный паритет отмечен в матрице,
а недостающие реальные материалы либо предоставлены, либо раздел честно скрыт до
публикации без мёртвых ссылок. Первый MVP можно показать раньше, но нельзя называть
его полной версией.
