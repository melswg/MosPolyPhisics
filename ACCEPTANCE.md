# Общие критерии готовности

Функция готова, только если одновременно выполнено следующее:

- сценарий проходит от интерфейса до backend и данных;
- вход валидируется сервером;
- предусмотрены loading, empty, invalid input и technical error;
- соседняя функциональность не удалена ради демонстрации;
- данные не выдуманы;
- строки пользователя отображаются безопасно;
- mobile около 390 px и desktop около 1440 px проверены в браузере;
- светлая и тёмная темы читаемы;
- всё важное доступно клавиатурой и имеет видимый focus;
- изображения загружаются и имеют подходящий alt;
- релевантные pytest/browser checks проходят;
- `git diff --check` проходит;
- diff не содержит БД, `.env`, секретов, логов и случайных файлов;
- `STATUS.md` отражает фактический результат и ограничения.

## Минимальный релиз готов, когда

- главная, «О нас» и новости наполнены подтверждённым материалом;
- пользователь регистрируется, входит, видит кабинет и выходит;
- администратор публикует новость, а гость её видит;
- посетитель проходит тест из пяти вопросов и получает разбор;
- запуск повторяем локально и через Docker;
- данные живут в постоянном volume, есть проверяемый backup;
- выполнен полный браузерный проход основных сценариев.

HTTPS, реальное письмо восстановления и public deployment нельзя считать
готовыми до предоставления домена/SMTP и фактической проверки.

## Полный релиз готов, когда

- по каждой строке `CURRENT_PRODUCT_INVENTORY.md` принято и выполнено решение:
  сохранить, улучшить, заменить подтверждённым материалом или явно отложить;
- нет ссылок на `#`, служебных maintenance-страниц и demo-seed в публичном пути;
- полностью работают новости, проекты, видео, календарь, новелла, тесты, ЕГЭ,
  викторина цитат, аккаунт и администрирование;
- минимальный объём материалов из `HERMES_BRIEF.md` подтверждён источниками;
- миграция публичного контента проверена на копии/экспорте, а пользовательские
  данные не переносились без отдельного решения владельца;
- пройдён полный browser smoke test в обеих темах на 390 и 1440 px;
- проверены HTTPS, SMTP, backup с восстановлением и rollback целевого deployment.
